# KarobarShah AI

KarobarShah AI is a multi-tenant AI-powered Clinic Management System built with modern web technologies.

## Features

- Multi-tenant architecture
- Secure authentication
- Team management
- Clinics, Doctors & Services management
- Patient management
- Appointment scheduling
- WhatsApp integration
- AI Receptionist
- AI Memory
- CRM
- Analytics Dashboard
- Calendar integration
- Voice Agent (Planned)

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- OpenAI / Anthropic
- Vercel

## Project Status

🚧 Under Active Development (MVP)

## Goals

Build a production-ready AI operating system for clinics with security, scalability, and automation as the primary focus.
